are indicative only.

## Dependencies & critical path

- Phase 02 depends on: Supabase project creation, domain decisions, Resend domain verification.
- Phase 04 decision gate: Arabic dialect eval on Haiku decides whether the `standard` profile keeps Haiku as default (A15).
- Phase 06 depends on: Meta Business verification, app review and test assets (lead time can be
  weeks — start the paperwork during Phase 03; RISK R-03).
- Phase 05 depends on: PayPal business account + sandbox credentials; plan ids per environment.
